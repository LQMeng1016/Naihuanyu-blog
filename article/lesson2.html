第 2 課 これからお世話になります

日语 · N5 · 今后请多关照 · 指示词与确认表达
📅 笔记日期：2026-08-05 📚 课程：日语 · 大家的日语初级1 🏷️ 标签：こそあど / そうです / ～か～か / の / そうですか 🧠 复习：下次 8-08

⚡ 本节课要点

  1. こそあど 四兄弟：近（こ）/ 远（そ）/ 最远（あ）/ 疑问（ど），物・连体・场所・方向四套
  2. 是否疑问句回答：肯定 はい、そうです ／ 否定 いいえ、ちがいます；～か～か 二选一
  3. の 可以「代替名词」；そうですか 降调 = 知道了

语法点

こ / そ / あ / ど 系列
指示词四兄弟，按距离分工：こ 离说话人近，そ 离听话人近，あ 离两人都远，ど 表疑问。有四套词性：
词性近远最远哪
事物（代词）これそれあれどれ
连体（接名词）このそのあのどの
场所ここそこあそこどこ
方向（礼貌）こちらそちらあちらどちら
これは辞書じしょですか。这是字典吗？
それは誰だれの傘かさですか。那是谁的伞？
そうです / ちがいます
用于回答「是否」的疑问句：肯定回答 はい、そうです，否定回答 いいえ、ちがいます。
それは辞書じしょですか。那是字典吗？
はい、そうです。是的，是这样。
いいえ、ちがいます。不，不是的。
～か ～か
二选一疑问句「是 XX 呢，还是 XX 呢」。回答要用 はい、XX です 或 いいえ、XX です 给出明确选择。
これはノートですか、本ほんですか。这是笔记本吗？还是书？
はい、本ほんです。是的，是书。
いいえ、本ほんです。不，是书。
名词 の（代替名词）
の 除了连接名词（所属/属性），还可以代替前面出现过的名词，避免重复。「～的（东西）」。
それは誰だれのかばんですか。那是谁的包？
佐藤さとうさんのです。是佐藤的（包）。
そうですか
接收到新信息时表示「知道了 / 原来如此」，语气降调。
これはあなたの本ほんですか。这是你的书吗？
いいえ、李りさんのです。不，是小李的。
そうですか。啊，这样啊。

易错点

⚠️ こそあ 距离别搞反
こ = 离说话人近（我这边），そ = 离听话人近（你那边），あ = 离两人都远（那边）。
✗ こ 离听话人近 → ✓ こ 是「我这边」的。

⚠️ この/その/あの/どの 后面必须接名词
它们是「连体词」，不能单独用：✗ これはこのです → ✓ この本は～。单独用要用 これ/それ/あれ/どれ。

⚠️ そうですか 的语气
降调 = 知道了（新信息）；如果升调 = 真的吗？/是吗？（表怀疑），意思完全不同。

⚠️ ～か～か 回答要完整
二选一疑问不能只答 はい/いいえ，要说「はい、本です」这样给出明确答案。
