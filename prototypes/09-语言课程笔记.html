第 5 課 電車で行きますか

日语 · N5 · 交通方式与时间表达
📅 笔记日期：2026-08-05 📚 课程：日语 · 大家的日语初级1 🏷️ 标签：交通 / ます形 / 助词 🧠 复习：下次 8-08

⚡ 本节课要点

  1. 「～で」表示交通工具（電車で行きます）
  2. ます形三兄弟：～ます / ～ません / ～ました
  3. 时间点 + に + 动词（7時に起きます）

本课单词先混个脸熟

日语读音中文
電車でんしゃでんしゃ电车
地下鉄ちかてつちかてつ地铁
新幹線しんかんせんしんかんせん新干线
バスバス公交车
タクシータクシー出租车
自転車じてんしゃじてんしゃ自行车
歩いてあるいてあるいて步行（て形）

语法点

～で ＋ 行きます
助词 で 跟在交通工具后面，表示「利用～」去做某事。注意 歩いて 是例外，不加 で。
電車でんしゃで行きますいきます。坐电车去。
何なにで来ましたきましたか。你怎么来的？
歩いてあるいて行きますいきます。走着去。
～ます / ～ません / ～ました
ます形三兄弟：现在肯定（ます）→ 现在否定（ません）→ 过去肯定（ました）。ませんでした 是过去否定。
毎日まいにちバスで行きますいきます。每天坐公交去。
今日きょうはタクシーで行きませんいきません。今天不打车去。
きのう地下鉄ちかてつで行きましたいきました。昨天坐地铁去了。
時間 ＋ に ＋ 動詞
具体时间点后面加 に。注意「毎日／今／昨日」这类词后面不加に。
七時しちじに起きますおきます。7 点起床。
九時くじに会社かいしゃへ行きますいきます。9 点去公司。

表达积累

何で行きますか。
怎么去？（问交通工具）
歩いて何分ですか。
走路要几分钟？
～は何時までですか。
～到几点？（问营业时间）
いっしょに行きませんか。
一起去吗？（邀请）

易错点

⚠️ に 和 で 别搞混
に 是「时间点/目的地」，で 是「交通工具/手段」。
「歩いて」不加 で ✗ 歩いてで → ✓ 歩いて行きます。
时间词「今・昨日・明日・毎日」后不加 に ✗ 毎日に → ✓ 毎日。
